## Regenerating the Data

To regenerate the concatenated samples without re-running the HPC pipeline:

```bash
cd "/Users/dhetting/Box Sync/2022-08-09_BSM_reduction/data/study_results/model_factors.20240613/068/combined_group_0/"
python combine_samples.py
```

This will:

1. Read 4 scenario Y CSV files: `combined_group_{scenario}_0.csv`
1. Read X from: `/Users/dhetting/src/bsm_sens_fy23/study_designs/delta/068/model_factors.20240613.delta.068.{scenario}.samples.csv`
1. Align X and Y by (scenario, run_id)
1. Concatenate across scenarios
1. Save as `sample_7500.X.parquet` and `sample_7500.Y.parquet`

## Note on the Configuration System

The public repo's configuration system (`configs/local/manuscript_paths.local.yml`) is designed for **toy data** with a specific schema (sample_id, x1, x2, AFSC, UAEORO). The real data (158 features, 23,495 outputs) is too large for the current schema validation.

To use the real data with the notebooks, either:

1. Load the data directly in notebook cells (recommended for reproducibility)
1. Extend the schema validation to support variable-size inputs/outputs
1. Resample/subset the real data to match the toy schema

The files documented here enable end-to-end reproducibility of the manuscript workflow using the complete scientific data.
